# local-whisper

Local, on-device Whisper transcription for audio and video on Mac.

Swift + WhisperKit. No cloud API. Offline by design.

## Status

Scaffold. CLI v0 is landing via cloud agent.

## Goals

- Transcribe audio and video files locally
- Extract audio from video with AVFoundation when needed
- Write plain text and optional SRT
- macOS CLI first
